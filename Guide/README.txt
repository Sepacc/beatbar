================================================================================
                           BEATBAR SUITE - GUIDE FOLDER
================================================================================

This folder contains user documentation and standalone Windows batch launcher
scripts for all applications in the Beatbar Suite:

DOCUMENTS:
  * guide.txt                - Comprehensive plain-text manual of all features,
                               usage guides, shortcuts, and dependency lists.
  * PROJECT_GUIDE.md         - GitHub-style Markdown documentation with tables,
                               architecture diagrams, and screenshots.

STANDALONE LAUNCHERS (.BAT):
  * install_dependencies.bat - Installs/updates all required Python libraries
                               and verifies FFmpeg.
  * run_beatbar_maker.bat    - Launches Beatbar Maker (Audio DSP & Rhythm Editor).
  * run_beatbar_viewer.bat   - Launches Beatbar Viewer (Video & Beatbar Player).
  * run_skin_maker.bat       - Launches Beatbar Skins Maker (Vector Skin Studio).
  * run_web_viewer.bat       - Launches Web Beatbar Viewer (Mobile & Browser Streamer).
  * run_launcher.bat         - Launches Suite Launcher & Studio Hub.

GETTING STARTED:
  1. First time? Run "install_dependencies.bat" to install required packages.
  2. Double-click any of the "run_*.bat" scripts above to launch that application.
  3. All scripts automatically detect the project root even if moved or copied.
================================================================================
